# 일본 세금환급 가이드

2026년 11월 개정 일본 면세 환급제도를 여행자 관점에서 정리한 정적 웹사이트입니다.

- [배포 사이트](https://xd1124.github.io/japan-tax-refund-guide/)
- [정보 출처 및 확인 상태](DATA_SOURCES.md)
- [사용자용 업데이트 내역](CHANGELOG.md)

## 로컬 실행

Node.js를 설치한 뒤 프로젝트 폴더에서 실행합니다.

```bash
npm install
npm test
```

웹사이트는 HTML/CSS/JavaScript 정적 페이지입니다. 브라우저에서 테스트하려면 VS Code Live Server 또는 로컬 HTTP 서버로 `index.html`을 엽니다. 브라우저 기능 테스트와 자동 검사는 서로 대체되지 않습니다.

## 현재 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 구조와 기존 인라인 코드 |
| `dashboard-ux.css`, `dashboard-ux.js` | 화면 이동·체크리스트·스크롤 UI 보조 |
| `store-finder.css`, `store-finder.js` | 매장 검색 및 상세 표시 |
| `stores-data.js` | 추가 지점·시설·브랜드 데이터 |
| `changelog.js` | 화면에 표시되는 업데이트 내역 |
| `tests/` | 매장 검색, 대시보드 UI, 환율 계산 테스트 |

현재 매장 데이터 일부는 `index.html`에, 나머지는 `stores-data.js`에 있습니다. 이 구조는 추후 **동작을 유지하면서** 단계적으로 통합합니다.

## 데이터 관리 기준

1. 공식 자료, 여행자 경험, 미확인 정보를 구분합니다.
2. 면세 가능 여부와 환급업체 확인 여부는 별도 상태입니다.
3. 브랜드 전체 정보를 개별 지점에 임의 적용하지 않습니다.
4. 출처와 확인 날짜는 `DATA_SOURCES.md` 및 데이터 항목에 기록합니다.
5. 제도·상점 정보를 업데이트할 때 기존 검색 기능과 체크리스트 저장을 테스트합니다.

## 변경·커밋 규칙

- 커밋 제목은 간결한 **한국어**로 작성합니다.
- 한 커밋에는 하나의 논리적인 변경만 담습니다.
- 변경 이유나 주의점이 있으면 본문에 짧게 적습니다.
- 사소한 기술 변경은 사용자용 업데이트 내역에 기록하지 않습니다.
- 배포 전에 자동 테스트와 모바일 화면을 확인합니다.
- 구조 변경은 별도 브랜치에서 검증하고, 승인 후 `main`에 반영합니다.

## 테스트 관련 주의

기존 일부 테스트는 과거 커밋의 `index.html`과 데이터를 `git show`로 비교합니다. 따라서 저장소의 Git 이력이 유지된 작업 디렉터리에서 실행해야 합니다. 이 의존성은 다음 리팩터링 과정에서 제거할 예정입니다.
